# Portfolio Rima Umaya

Letakkan semua file ini dalam **satu folder yang sama**, lalu upload ke GitHub.

## Struktur Folder
```
/
├── index.html               ← rename dari rima-portfolio-v6.html
├── RIMA_UMAYA_CV.jpg        ← CV (tombol Download CV)
├── cert-graphic-design.pdf
├── cert-digital-marketing.pdf
├── cert-dasar-marketing.pdf
├── cert-service-center.pdf
├── cert-hardware.pdf
└── README.md
```

## Cara Upload ke GitHub Pages
1. Buat repository baru di github.com (misal: `portfolio-rima`)
2. Upload semua file di atas ke repository
3. **Rename** `rima-portfolio-v6.html` → `index.html`
4. Buka **Settings → Pages → Branch: main → Save**
5. Portfolio live di: `https://username.github.io/portfolio-rima`
